# CREVALUE 대표님 전용 시험판

2026-10-09. 브리딩비서와 같은 저장소·계정·데이터베이스를 사용합니다. 일반 사용자의 홈과 개체 상세에는 메뉴가 표시되지 않으며, 실제 사진 분석은 PC 프로그램에서 Supabase의 사용자 인증 결과가 기존 대표님 계정과 일치할 때만 허용합니다. 소스 공개 여부와 사용 권한은 별개입니다.

## 사용 방법

1. PC 폴더의 `크레밸류_실행.bat`를 실행합니다. Node.js와 이 프로젝트의 npm 의존성, 기존 ChatGPT 구독으로 로그인한 Codex가 필요합니다. API 키는 필요하지 않습니다.
2. 열린 브리딩비서에서 대표님 계정으로 로그인하고 홈의 **크레밸류**, 또는 개체 상세의 **AI 퀄리티 분석 · 크레밸류**를 누릅니다.
3. 사진을 1~6장 선택하거나 사용 권한이 있는 HTTPS 사진 주소를 불러오고 모프 기준을 확인한 뒤 **사진 분석하기**를 누릅니다. 사진은 장당 긴 변 최대 1600px JPEG로 변환하여 EXIF를 제외합니다.
4. 요청은 먼저 계정의 서버 대기열에 저장합니다. PC가 연결되면 한 건씩 분석하고 결과를 저장합니다. **평가 기록**에서 다시 열 수 있습니다.
5. PC의 크레밸류 탭을 열어 두십시오. 이 탭이 브리딩비서의 로그인 세션을 갱신해 PC 분석기에 전달합니다. PC 재시작 뒤에는 실행 파일을 다시 열고 크레밸류에 한 번 접속합니다. PC가 꺼졌거나 로그인 세션이 만료되면 서버에 대기하며, 다시 연결한 뒤 처리합니다.

모바일에서 등록한 요청도 같은 계정의 서버 대기열에 저장됩니다. PC 브라우저가 연결된 동안 처리합니다. 휴대폰에서 표시하는 PC 연결 상태는 해당 기기의 localhost 상태이므로 대기 중으로 표시될 수 있으나, 서버 결과는 조회할 수 있습니다. 일부 브라우저는 로컬 네트워크 연결 허용을 한 번 요청할 수 있습니다.

## 구독 사용 한도

`@openai/codex` app-server의 `account/read`로 ChatGPT 구독 인증인지 확인합니다. 유료 API용 환경변수는 분석 자식 프로세스에 전달하지 않으며 ChatGPT 로그인만 허용합니다. `account/rateLimits/read`의 Codex 단기·주간 창 중 가장 적게 남은 잔여율을 사용합니다.

- **잔여량 10% 이하: 분석 시작 거부.** 한도 확인 실패도 분석을 시작하지 않습니다.
- 분석 시작 직전 두 번 확인하고, 실행 중에도 15초마다 조회하여 제한에 도달하면 중단을 요청합니다.
- 공급자의 사용량 집계 지연, 이미 처리 중인 요청 및 동시에 사용하는 다른 Codex 작업 때문에 정확히 10.000%를 보장하는 결제 한도는 아닙니다. 추가 분석 시작을 차단하는 보호선입니다.
- 이 보호는 사진 분석기에만 적용하며, 개발 작업에는 적용하지 않습니다. 추가 크레딧 구매나 유료 API 전환은 구현하지 않았습니다.

## 외형 평가·비교

노멀, 할리퀸, 익스트림 할리퀸, 핀스트라이프, 릴리화이트, 아잔틱, 카푸치노, 프라푸치노, 세이블, 초초, 하이포, 달마시안, 크림시클, 팬텀을 지원합니다. 복합 모프는 항목을 합치고 중복 가중치를 평균낸 뒤 정규화합니다. 명칭·가중치는 **브리더 검토 전 임시 가설**입니다. 노멀·릴리화이트·아잔틱부터 실제 보유 개체로 검증합니다.

AI는 항목별 관찰, 근거, 사진 ID, 관찰 가능 여부, 0~4 단계, 관찰 확신을 JSON으로 반환합니다. 별도 엔진이 단계를 0·25·50·75·100으로 변환하여 가중 평균합니다. 평가 불가는 분모에서 제외하며 관찰 범위 45% 미만 또는 관찰 항목 두 개 미만이면 종합 점수를 보류합니다. 사진이 아닌 그림·다른 동물·대상 불명확 사진에도 점수를 만들지 않습니다. 꼬리 외관은 설명만 하며 일률적으로 감점하지 않습니다.

0~100점은 공식 등급·시세·건강·유전 보유 여부가 아닙니다. 관찰 확신도 검증된 정확도가 아닙니다. 각 결과에 모델과 기준 버전, 프로파일 전체와 사용 사진을 기록합니다. 유전자형·헷·성별·건강·번식력을 사진으로 확정하지 않습니다.

같은 사진·모프·촬영 상태·기준 버전은 완료된 결과를 재사용합니다. 새 사진 ID로 근거를 다시 연결합니다. 재현성 검증 체크박스로 실제 재관찰도 가능합니다. 수동 평가는 별도 `source: manual`로 저장합니다.

두 기록을 선택하면 공통 항목과 근거 점수를 비교합니다. 같은 개체의 날짜별 기록으로 성장 비교가 가능합니다. 모프나 기준 버전이 다르면 종합 점수의 우열을 단정하지 않습니다. 브리더 두 명의 항목별 블라인드 선호와 AI 결과를 저장하고 일치·불일치 내역을 집계합니다. 이는 사람 의견과의 일치이며 정답률이 아닙니다. 이미 AI 결과를 연 기록은 블라인드로 집계하지 않습니다. 블라인드 비교용 체크박스를 켜면 분석 완료 시 점수를 가려 둡니다. 결과 공개 이력은 브라우저와 서버에 기록하여 다른 화면·기기로 옮겨도 블라인드로 되돌리지 않습니다.

## 데이터 모델 및 보존

기존 `cg_records`의 사용자별 RLS와 JSONB를 재사용합니다. 파괴적인 테이블 변경이나 기존 개체·일정·설정 마이그레이션은 없습니다.

| 종류 | 내용 |
|---|---|
| `crevalue` | 요청, 개체 연결, 촬영 사진/각도/파이어 상태, 성장 정보 스냅샷, 상태, 외형 결과, 기준·모델 버전, 학습 동의 분리 |
| `crevalue_market` | 등록가/최종가, 거래·검증 상태, 개체 연결, 혈통·검증 유전, 평가 연결, 출처·권한·지역·거래 조건, 수정 및 가격 이력 |
| `crevalue_feedback` | 두 평가 ID, 평가자, 항목별 선택, 블라인드 여부, 날짜·버전 |

기존 브리딩비서 동기화는 이 새 종류를 기존 개체로 취급하지 않습니다. 로그인 토큰은 PC 분석기 메모리에만 보관합니다. 사진과 분석 이력은 `%LOCALAPPDATA%\Crevalue\jobs.json`에도 보관하며 토큰은 저장하지 않습니다. 강제 종료 중이던 분석은 복구 시 오류로 보존하여 자동 중복 소비를 피합니다. 실행 직전 대표님 인증을 다시 확인하고, 서버의 사진 해시를 확인하고 queued 상태·수정 시각을 조건부 PATCH로 선점한 분석기만 구독을 사용합니다. 선점 의도를 로컬에 먼저 저장하고, 결과 저장도 작업자·실행 ID·진행 상태를 대조하여 중복 실행과 오래된 PC의 덮어쓰기를 막습니다. 파일 잠금이 해제되면 이후 저장을 다시 시도할 수 있습니다.

서버·가격·피드백 목록은 500건씩 페이지를 나누어 읽습니다. PC는 대기 요청만 다섯 건씩 읽어 이미 완료된 사진을 매번 내려받지 않습니다. 수만 건의 가격 자료는 현재 통계 모듈에 연결할 수 있지만, 사진 이력까지 수만 건이 되면 별도 오브젝트 저장소와 SQL 집계로 분리하는 것이 다음 단계입니다.

분석 제공자는 `CodexProvider`의 `quota() / analyze(job,cwd) / close()` 인터페이스로 분리했습니다. 가격·CSV·피드백 모듈은 AI 공급자와 독립적입니다.

## 거래 입력 및 참고 가격

직접 입력, 빈 CSV 템플릿 다운로드, CSV 검사·가져오기, 수정·삭제 표시, 중복 탐지, 기존 브리딩비서 개체·분양 기록 불러오기를 지원합니다. 기존 판매 완료 상태를 불러와도 거래가 검증 상태는 자동으로 검증 완료가 되지 않습니다. 삭제는 기존 행을 보존하는 소프트 삭제입니다.

CSV는 UTF-8이며 첫 행 열 이름을 유지합니다. `morph`는 `normal`, `lilly` 등 기준 키이며 복합은 `lilly+axanthic`입니다. `sex`: unknown/male/female, `status`: unsold/sold/cancelled/incomplete, `verification`: unverified/verified, `rights`: unknown/owned/permission, `geneticsVerification`: unknown/verified. 가격은 원, 체중은 g, 날짜는 YYYY-MM-DD입니다. `source`에 자료 출처와 확인 기록을 남기십시오. 평가 점수가 있으면 `assessmentVersion`을 함께 입력합니다. 오류가 있으면 해당 가져오기 전체를 저장하지 않습니다. 한 번에 최대 5,000행을 하나의 서버 트랜잭션으로 저장합니다. 권한 미확인 자료는 보관 가능하지만 가격 계산에서는 제외합니다.

기본 최소 표본은 **최근 180일 검증 실거래 10건**입니다. 등록가를 최종 거래가로 대체하지 않습니다. 같은 모프, 입력한 성별, 유사 체중(±30% 또는 5g), 지역·혈통·검증 유전·거래 조건을 필터링합니다. 외형 점수를 지정하면 같은 버전 ±15점만 비교합니다. 가격 IQR 1.5배 밖의 이상치를 제외하고 남은 가격의 중앙 50% 범위를 제시합니다. 표본 수·분산·최근 60일 자료 수로 낮음/보통을 구분하며 높음은 표시하지 않습니다. 최소 표본과 기간은 함수 설정으로 변경할 수 있습니다.

가격 자료가 없거나 부족하면 **유사 실거래 자료 부족으로 신뢰할 수 있는 가격 범위를 제공할 수 없습니다.**를 표시합니다. 거래 자료를 무단 수집하는 기능은 없습니다.

## 현재 제한 및 다음 순서

1. 실보유 약 100마리의 사용 권한 있는 사진과 두 평가자의 기준 검토가 필요합니다. 현재 외형 점수는 기술 흐름 검증이며 숙련 브리더 수준의 성능 인증이 아닙니다.
2. 사진 품질별 통계, 순위 상관, 근거의 정확성, 재관찰 편차의 전문 분석 대시보드는 다음 단계입니다. 원본 관찰·피드백·사진·버전을 내보내어 분석할 수 있습니다.
3. 등록 계정 범위를 확대하는 테스터 관리 및 공개 판매는 하지 않았습니다.
4. Windows 재시작 후 자동 실행 등록은 하지 않습니다. 실행 파일을 열면 백그라운드로 동작합니다. 로그인 세션 유지에는 PC의 크레밸류 탭이 필요합니다.
