# 크레밸류 자료 입력·검증 사용법

2026-10-23 · 자료 형식 v2 · 대표님 전용

## 사진 자료를 넣는 순서

1. 대표님 계정으로 브리딩비서에 로그인한 뒤 **크레밸류 → 자료 입력·검증 → 사진 세트**를 엽니다.
2. 기존 개체를 선택하거나 개체 ID·이름을 직접 입력합니다. 같은 개체는 같은 ID를 계속 사용합니다.
3. 촬영일, 모프 원문, 개발/조정/최종 검증 용도, 사진 사용 권한을 입력합니다. 모프가 미확정이어도 저장할 수 있으나 모프 분석은 보류합니다.
4. 가족·성장·촬영 조건을 펼쳐 가족 그룹, 촬영 당시 체중·측정일·성별과 조명 등을 적습니다. 현재 체중·성별을 과거 촬영 값으로 자동 입력하지 않습니다.
5. 사진 1~6장을 선택하고 사진마다 각도와 파이어 상태를 고릅니다. 등·좌측·우측·전신을 권장합니다.
6. **사진 세트 저장**은 자료만 저장하며 AI를 호출하지 않습니다. 저장 후 서버에서 다시 조회해 확인합니다.
7. 저장한 세트의 **분석 화면에 불러오기 → 사진 분석하기**를 눌러야 분석을 접수합니다. 기본적으로 블라인드용 결과 가림을 켭니다.

개체/가족/동일 사진이 다른 검증 용도에 섞이거나, 다른 개체에 같은 사진을 등록하면 입력을 막습니다. 촬영 세트는 고정 기록이며 새 촬영은 새 세트로 추가합니다. 분석 화면에서 원래 세트의 사진·각도·파이어 상태·모프를 바꾸면 세트를 다시 불러오거나 일반 평가로 전환해야 합니다.

사진은 긴 변 최대 1600px JPEG로 저장하고 원본 파일 해시를 중복 확인에 사용합니다. 원본 파일은 별도로 보관하십시오. 업로드 사진을 모델 학습에 제공하는 동의를 자동으로 설정하지 않습니다.

## 거래 자료를 넣는 순서

**자료 입력·검증 → 거래 자료**에서 직접 입력하거나 빈 CSV 양식을 받습니다.

- 거래 ID는 거래마다 고유하게, 개체 ID는 사진 세트와 같게 입력합니다.
- 등록가와 최종 개체 금액을 구분합니다. 배송비·용품비를 분리할 수 없으면 일반 가격 자료로 사용하지 않습니다.
- A: 최종금액·완료 근거 확인, B: 판매자의 최종금액 진술, C: 판매완료 표시만 확인, D: 등록가만 확인입니다.
- A등급은 최종금액, 거래일, 완료일, 근거, 확인자·확인일이 있어야 저장할 수 있습니다. 개인정보 원문 대신 확인 방법이나 본인 자료 참조명을 적습니다.
- 사진 연결 시 같은 개체의 거래 당일 또는 그 이전 촬영 세트만 허용합니다.
- 미판매·예약·완료·취소·철회를 구분합니다. 묶음·교환·급매·지인·경매는 별도로 보관하며 일반 거래 계산에서 제외합니다.
- **수정 기록 추가**는 이전 기록을 지우지 않습니다. 등록가를 바꾸면 실제 변경일을 적습니다. 입력일과 가격 변경일을 구분해 이력에서 볼 수 있습니다.

CSV는 UTF-8, 날짜는 YYYY-MM-DD, 금액은 쉼표 없는 원 단위 숫자입니다. 최대 500행/5MB이며 **오류 검사 → 결과 확인 → 전체 저장** 순서입니다. 중복·날짜·필수값 오류가 하나라도 있으면 저장하지 않습니다. 저장 직전 다시 검사하고 전체 묶음을 단일 전용 레코드로 저장합니다. 서버 응답이 끊겼다면 재입력 전 새로고침으로 저장 여부부터 확인하십시오.

현재 가격 기능은 최근 유사 거래의 중앙 50% 분포이며 미래 가격 예측이 아닙니다. 검증된 국내 원화 단독 일반 거래만 사용하며, 같은 개체의 중복 거래·대상 자체의 거래·다른 유전 주장을 제외합니다. 새 자료는 기존 거래·가격 화면의 옛 데이터와 자동 혼합하지 않습니다.

## 두 사람 독립 평가

1. 같은 모프의 서로 다른 개체 사진 세트를 선택하고 평가자 구분 이름 두 개로 회차를 만듭니다. 좌우는 무작위입니다.
2. 첫 평가자가 모든 항목을 왼쪽/오른쪽/비슷함/판단 불가로 선택하고 근거를 적어 **제출·잠금**합니다.
3. 평가자를 바꿔 두 번째 평가를 제출합니다. 첫 평가의 내용은 표시하지 않습니다.
4. 두 사람 제출 후에만 **두 사람 평가 공개**가 가능합니다. 제출한 의견은 수정하지 않으며 다시 평가하려면 새 회차를 만듭니다.
5. AI 결과나 다른 사람 의견을 이미 봤는지, 개체를 알아봤는지 기록합니다. 앱의 기존 AI 공개 이력도 조회하며 사전 노출은 블라인드 집계에서 제외합니다.

이 기능은 대표님 한 계정에서 차례로 입력하는 절차입니다. 별도 평가자 인증·계정별 비밀 보관 시스템은 아닙니다. 다른 기기의 동시 중복 제출이 감지되면 해당 회차를 집계에서 제외합니다.

## 검증 현황

- 촬영 세트 수와 서로 다른 개체 수, 검증 용도별 개체 수, 가격 계산 가능한 거래 수, 사진 연결 거래 수를 구분합니다.
- 두 사람 의견 일치율은 AI 정확도가 아닙니다. 미공개·미완료·사전 노출 회차를 집계하지 않습니다.
- **저장된 AI 결과와 검증**은 기존 결과만 읽으며 새 AI를 호출하지 않습니다. 회차 생성 전 첫 AI 관찰, 같은 모델·기준·모프, 관찰 범위 80% 이상, 사전 공개되지 않은 기록을 비교합니다. 사람 의견이 일치하지 않는 항목은 보류합니다.
- 재관찰 편차는 같은 세트·모델·기준에서 `기존 결과를 재사용하지 않고 다시 관찰하기`로 생성한 기록이 두 개 이상일 때 계산합니다. 캐시 재사용을 재관찰로 세지 않습니다.
- 전체 자료·사진과 검증 메타데이터를 JSON으로 내보낼 수 있습니다. JSON 재가져오기는 이번 범위에 포함하지 않았습니다.

## 저장 경계와 구현 범위

새 자료는 기존 대표님 인증/소유자 행 권한을 사용하는 `crevalue_feedback` 안에서 `cv2-` ID와 schemaVersion 2로 분리합니다. 사진 바이트는 개별 조회에서만 받고 목록은 메타데이터 요약을 사용합니다. 운영 테이블·권한·기존 개체·급여·산란·분양 저장 형식을 변경하지 않습니다. 기존 분석 결과와 기존 크레밸류 거래도 덮어쓰지 않습니다.

사진 세트·거래 수정·독립 평가의 원본은 보존합니다. 여러 기기에서 동시에 수정해 거래가 갈라진 경우 해당 거래는 가격 계산에서 제외하고 검증 현황에 충돌을 표시합니다. 데이터가 쌓였다는 이유만으로 신뢰도를 높음으로 표시하지 않습니다.

자동 평가 기준 교정, 외부 성능 인증, 미래 가격 모델 학습, 판매기간 예측, 일반 사용자 공개는 이번 구현 범위가 아닙니다.

## 검증 기록

- 자동 시험: 169개 통과. 기존 회귀 155개와 새 데이터/권한/블라인드/사진 연결/CSV/AI 집계 시험 14개.
- 브라우저 시험: 별도 합성 자료로 사진 저장·재조회, 거래 오류/저장, CSV 검사/전체 저장, 독립 제출/공개, AI 결과 조회, 비소유자 거부, 390px 가로 넘침 없음, 기존 브리딩 저장값 보존 확인.
- Windows 줄바꿈 때문에 실패하던 기존 소스 검사 두 곳은 읽을 때만 CRLF를 LF로 정규화했습니다. 앱 동작 변경은 없습니다.
- 실제 계정에서 새 자료를 저장한 검증과 실제 사진 판단 품질·거래 예측 정확도 검증은 별도입니다. 테스트가 통과했다고 그 검증이 완료된 것으로 보지 않습니다.

개발 검증 명령: `npm test`, `node tests/crevalue-dataset.browser.mjs`.
