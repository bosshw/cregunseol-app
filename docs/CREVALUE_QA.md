## 실제 모델 호출

ChatGPT 인증 + 프로젝트 전용 Codex 0.162.0 + gpt-6-astra로 실제 이미지 입력·구조화 응답을 확인했습니다. API 키를 사용하지 않았습니다.

- CC0 실물 게코 사진: **50점, 관찰 범위 45%**. 잎에 가려진 몸통 비율·전체 균형은 평가 불가, 보이는 색·대비만 평가했습니다.
- 출처: Vassil, [Correlophus ciliatus Genève 24102014 A](https://commons.wikimedia.org/wiki/File:Correlophus_ciliatus_Gen%C3%A8ve_24102014_A.jpg), CC0. 기술 시험용이며 대표님 소유 개체의 평가나 학습 자료가 아닙니다.
- 앱 아이콘(그림) 입력: 실제 모델이 `not_gecko`, 종합 점수 없음, 관찰 범위 0%를 반환했습니다.
- 로컬 브라우저: 기존 사진 로딩, HTTPS 사진 주소 입력, 수동 64점 저장, 두 기록 사진/항목 비교, CSV 오류 차단 및 10건 일괄 입력, 102,250~106,750원 합성 거래 범위를 확인했습니다. 모바일 390px에서 가로 넘침 없이 표시했습니다.
- Chrome 확장의 파일 URL 접근 권한이 없어 자동 파일 선택 시험은 하지 못했습니다. 사진 로딩·리사이즈는 기존 사진 및 공개 사진 주소 입력으로 확인했습니다.
- 로그인 재검증, PC 재시작 대기, 일시적인 디스크 잠금 복구, 두 PC의 원자적 작업 선점 추가 시험을 통과했습니다.
- OpenQodex 0.10.0은 Windows 경로 오류(`C:\C:`)로 실행되지 않았고 스캐너를 실행하지 못했습니다. 별도 Codex 모델에 변경 소스 전체를 제공해 독립 검토했고, 지적 사항을 수정한 뒤 재검토했습니다. 최종 재시도 경쟁 조건에 관한 집중 재검토에서도 남은 구체적 결함이 없다는 응답을 확인했습니다. `npm audit` 취약점 0건.
